# 番茄钟网页需求

## 已实现功能

### 计时功能
- 四种专注模式：标准(25分钟)、作业(45分钟)、复习(20分钟)、考试(90分钟)
- 自定义时长：点击时间数字可调整专注/休息时长
- 开始/暂停/重置/跳过按钮
- macOS风格圆环进度条：深色圆环从顶部顺时针消耗

### 提醒功能
- 完成时播放提示音
- 浏览器通知提醒（需授权）
- 休息时显示活动建议

### 学习记录
- 科目选择：开始前选择学习科目
- 学习日记：专注完成后可记录学习内容
- 历史记录：保存每次专注的时长、模式、科目、日记

### 统计报告
- 今日统计：完成番茄数、专注时长
- 历史统计：累计天数、总时长
- 周报/月报：每日专注趋势、科目分布、日记回顾

### 成就系统
- 里程碑成就：累计专注1/10/50/100小时
- 每日成就：单日完成1/3/5/10个番茄
- 成就徽章展示

### 界面设计
- 极简风格：无边框、透明背景
- 响应式设计：自适应手机和桌面
- 本地持久化：所有数据保存在localStorage

## 技术实现

- Vue 3 + Composition API
- Vite 构建工具
- GitHub Pages + Actions 自动部署
- 纯前端实现，无需后端
